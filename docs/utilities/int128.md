## Overview

Helpers for using GCC/Clang `__int128_t` and `__uint128_t` in competitive programming. The header provides aliases, string conversion, parsing, and stream operators.

## Aliases

| Alias | Type |
| --- | --- |
| `m1une::utilities::i128` | `__int128_t` |
| `m1une::utilities::u128` | `__uint128_t` |

## Requirements

Let `D` be the number of decimal digits, including an optional sign.
Parsed values and every later arithmetic result must fit in the destination
128-bit type. The parsing functions validate decimal syntax but do not report
out-of-range values; unsigned arithmetic wraps and signed overflow is invalid.
Stream extraction leaves the destination unchanged if reading the token fails.

## Functions

| Function | Description | Complexity / Throws |
| --- | --- | --- |
| `std::string to_string(i128 x)` | Converts a signed 128-bit integer to decimal. | $O(D)$ |
| `std::string to_string(u128 x)` | Converts an unsigned 128-bit integer to decimal. | $O(D)$ |
| `i128 parse_int128(const std::string& s)` | Parses a signed decimal string. | $O(\lvert s \rvert)$; throws `std::invalid_argument` for invalid input. |
| `u128 parse_uint128(const std::string& s)` | Parses an unsigned decimal string. | $O(\lvert s \rvert)$; throws `std::invalid_argument` for invalid input. |
| `operator<<` / `operator>>` | Reads and writes decimal values through standard streams. | Linear in the number of digits. |

## Example

```cpp
#include "utilities/int128.hpp"
#include <iostream>

int main() {
    using m1une::utilities::i128;

    i128 x = 0;
    if (!(std::cin >> x)) return 0;
    x *= 1000000000000000000LL;
    std::cout << x << "\n";
}
```
