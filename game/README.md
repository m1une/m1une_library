# Game Theory

Header-only normal- and misere-play helpers use the `m1une::game` namespace.

| Header | Contents |
| --- | --- |
| `nim.hpp` | Nim sums, outcomes, and explicit winning moves for ordinary and misere Nim. |
| `nim_product.hpp` | 64-bit nimber multiplication, powers, inverses, and quotients. |
| `grundy.hpp` | Sprague-Grundy numbers for explicitly represented finite DAG games. |
| `retrograde_analysis.hpp` | Win/lose/draw analysis for finite directed games with possible cycles. |
| `subtraction_game.hpp` | Grundy tables and disjoint sums for fixed subtraction move sets. |
| `green_hackenbush.hpp` | Green Hackenbush forests represented by edge-parent arrays. |
| `silver_dollar_game.hpp` | Coin-sliding Grundy numbers on a one-dimensional strip. |
| `all.hpp` | Includes every public game header. |
